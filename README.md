# wikipedia-top-reads

Project for compiling and researching top read articles on English Wikipedia.

Each day's report looks at why articles ranked among the most-read on Wikipedia, using pageview data, article edit history, talk pages, and news coverage. Reports are published as a static site with GitHub Pages, and previous reports are kept in the archive.

## About this report

This report was generated using Claude, an AI assistant made by Anthropic. It is based on Wikipedia pageview data and article content, and it links to the news sources it draws on. Those sources remain the property of their respective publishers.
